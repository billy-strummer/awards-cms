Manage and review award submissions

Getting Started — Award Management

Follow the award lifecycle from creation through to winner announcement.

1
Create Award Categories
Click "Add Award" to create each award category. Set Year, Sector, and Region to organise them.
2
Set Status to Active
Change status from Draft → Active to open the award for entries. Use Phase to track progress through judging stages.
3
Manage Judging
Use the Assignments panel (trophy icon on each row) to assign nominees to judges and record decisions.
4
Announce Winners
Go to Winners to record and publish results. Set award status to Archived once the programme is complete.
