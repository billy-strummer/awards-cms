Award Management

Manage and review award submissions

Getting Started — Award Management

Follow the award lifecycle from creation through to winner announcement.

1
Create Award Categories
Click "Add Award" to create each award category. Set Year, Sector, and Region to organise them.
2
Set Status to Active
Change status from Draft → Active to open the award for entries. Use Phase to track progress through judging stages.
3
Manage Judging
Use the Assignments panel ( people icon on each row) to assign nominees to judges and record decisions.
4
Announce Winners
Go to Winners to record and publish results. Set award status to Archived once the programme is complete.

    Getting Started — Winners

    Winners can be added manually, imported via CSV, or promoted from the judging panel.

    1
    Add Winners
    Add winners manually using "Add Winner", import in bulk via CSV, or promote shortlisted nominees from Assignments.
    2
    Record GDPR Consent
    Before publishing a winner's name or image, record their GDPR consent using the Consent checkbox on each row.
    3
    Update Status
    Move each winner through: Pending → Notified → Pack Sent → Confirmed → Published as you progress.
    4
    Announce Publicly
    Set status to "Published" to make the winner visible on public pages. Upload photos and winner story for maximum impact.
